# アイコン色の固定パレット化 実装計画

- 作成日: 2026-08-26
- 対象: ユーザーアイコンの色選択UI（`IconSettingModal.tsx`）を、自由入力のカラーピッカー（`input type="color"`）から固定12色（白を除く）のスウォッチ選択に変更する

## 1. 背景・要件

- 現在、アイコン色は `input type="color"` による自由なカラーピッカーで選択できる。
- これを「一般的な12色（白色を除く）」の固定パレットから選ぶ方式に変更したい。
- 調査の結果、このアプリで `input type="color"` が使われている箇所は `IconSettingModal.tsx` の1箇所のみで、他に色選択UIは存在しない（描画色は全て `black` 固定でユーザー選択不可）。そのため変更対象は一意に確定できる。

## 2. 現状構造の整理

| 目的 | ファイル | 該当箇所 |
|---|---|---|
| カラーピッカーUI本体 | `components/organisms/top/IconSettingModal.tsx` | 56-67行目 `input type="color"` |
| 呼び出し元・保存確定 | `components/pages/Top.tsx` | 41-44行目 state、229-243行目 `onSave` |
| デフォルト色/アイコン一覧定義 | `utils/Icons.ts` | 6-7行目 `DEFAULT_ICON_COLOR = "#000000"` |
| localStorage保存 | `lib/user.ts` | 116-130行目 `getIcon`/`setIcon` |
| DB保存（Server Action） | `app/user/action.ts` | 11-38行目 `ensureUser` |
| DBスキーマ | `prisma/schema.prisma` | 19行目 `icon_color String? @default("#000000")` |
| 表示コンポーネント | `components/atoms/UserIcon.tsx` | react-icons の `color` propに `icon_color` をそのまま渡す |

- `icon_color` はDB上 `String?`（HEX文字列、バリデーション制約なし）で保存されている。**固定パレット化してもDBスキーマ・型は変更不要**（保存される値がHEX文字列であることに変わりはないため）。
- `DEFAULT_ICON_COLOR = "#000000"`（黒）は既存のまま維持できる（黒はパレットに含める想定）。

## 3. 実装方針

### 3.1 固定12色パレットの定義

`utils/Icons.ts` に新規定数 `ICON_COLORS`（または別ファイル `constants/iconColors.ts`）として12色を定義する。

案（一般的な色鉛筆/クレヨンセットに準拠、白を除く12色）:

| 色名 | HEX |
|---|---|
| 黒 | `#000000` |
| 赤 | `#FF0000` |
| 橙 | `#FFA500` |
| 黄 | `#FFD700` |
| 黄緑 | `#9ACD32` |
| 緑 | `#008000` |
| 水色 | `#00BFFF` |
| 青 | `#0000FF` |
| 紺（藍） | `#000080` |
| 紫 | `#800080` |
| ピンク（桃） | `#FF69B4` |
| 茶 | `#8B4513` |

※ 具体的な12色の組み合わせ・HEX値は最終決定前にユーザー確認を取る（セクション6参照）。

### 3.2 UIの変更（`IconSettingModal.tsx`）

- 56-67行目の `input type="color"` を、12色のスウォッチボタン群（グリッド表示、円形または角丸四角のカラーチップ）に置き換える。
- 各スウォッチをクリックすると `setSelectedIconColor(hex)` を呼び、選択中の色には枠線やチェックマークなどの選択状態表示を付与する（既存の「アイコン一覧グリッド」40-53行目の選択UIパターンと統一感を持たせる）。
- プレビュー用の `UserIcon` へのリアルタイム反映ロジック（30-36行目）はそのまま流用可能（`selectedIconColor` の値がHEX文字列である点は変わらないため）。
- 「設定」ボタン押下時の `onSave(selectedIconName, selectedIconColor)` 呼び出し（69-75行目）も変更不要。

### 3.3 影響範囲の確認

- `Top.tsx` の `onSave` コールバック、`lib/user.ts` のlocalStorage保存、`app/user/action.ts` のDB保存、`prisma/schema.prisma` のスキーマ、`UserIcon.tsx` の表示ロジック — **いずれも「HEX文字列を受け取って保存/表示する」という契約は変わらないため修正不要**。
- 既存ユーザーが過去に自由入力で選んだ色（パレット外のHEX値）がDBに残っている場合、そのまま表示は継続される（`UserIcon` はどんなHEX文字列でも表示可能）。ただし次回アイコン設定モーダルを開いた際、パレットにない色は「どれも選択中でない」状態になる点は許容する（またはモーダル初期表示時に最も近い色 or デフォルト黒にフォールバックするか、対応方針を要確認）。

## 5. 動作確認観点

- アイコン設定モーダルで12色のスウォッチが表示され、白が含まれていないこと
- スウォッチ選択で `UserIcon` プレビューの色がリアルタイムに変わること
- 「設定」保存後、localStorageとDB（`m_user.icon_color`）双方に選択したHEX値が保存されること
- `UserScoreBoard` / `AnswererGuideCard` など既存の `UserIcon` 表示箇所に反映されること

## 6. 未決事項（実装着手前に確認したいポイント）

1. **12色の具体的な内訳**: セクション3.1の案（黒赤橙黄黄緑緑水色青紺紫ピンク茶）でよいか、別の配色基準（例: Material Design標準色、Tailwindの色、CSS基本色など）を使うか
2. **既存ユーザーのパレット外カラーの扱い**: 過去に自由入力で保存された色（パレットに存在しないHEX値）を持つユーザーがモーダルを開いた際、「未選択状態」にするか「デフォルト黒にフォールバック」するか
3. **スウォッチのUIデザイン**: 円形/四角形、サイズ、グリッドの列数など見た目の指定有無
