# rooms.geohash カラム追加

作成日: 2026-09-14
対象: `prisma/schema.prisma` (`Room` モデル / `rooms` テーブル)

## 1. 目的

- 現在地の座標を取得し、ハッシュ化(geohash化)した値を `rooms` テーブルに保存する
- 「だいたいこの辺」という粗い位置情報として利用する。正確な位置の特定は目的としない

## 2. 背景・要件(セキュリティ観点)

正確な位置精度は不要という要件がある。これはセキュリティ上の理由によるもので、DB(および経路上のログ等)に個人の正確な位置が残ることを避けるための設計とする。

- 生の緯度経度はDBに保存しない
- geohashの桁数を短く(粗く)し、意図的に精度を落とす
- クライアントから受け取った高精度座標は、サーバー側でgeohash化した時点で破棄する(アクセスログ等にも生の座標を残さない)

詳細なセキュリティ要件のすり合わせは別途相談予定。

## 3. カラム設計

### Prisma schema

```prisma
model Room {
  ...
  geohash String? @db.VarChar(5)
  ...

  @@index([geohash])
  @@map("rooms")
}
```

| 項目 | 設定 | 理由 |
|---|---|---|
| 型 | `varchar(5)` | 桁数を物理的に5桁までに制限し、それ以上の精度が入り得ない設計にする |
| NULL許容 | nullable | 位置情報取得はユーザー許可制のため、取得できない/拒否されたケースがある |
| インデックス | `@@index([geohash])` | 前方一致(prefix)による絞り込み検索を想定 |
| デフォルト値 | なし | リクエスト時にサーバー側で都度計算してセットする値のため不要 |

### 精度の目安(桁数と誤差範囲)

| 桁数 | 誤差範囲 | 感覚 |
|---|---|---|
| 4 | 約20km四方 | 市区町村〜広域 |
| **5(採用)** | **約4.9km四方** | **町丁目〜駅圏くらい** |
| 6 | 約1.2km四方 | かなり絞れる(個人特定リスクが出始める) |
| 7以上 | 153m以下 | 個人特定につながりうるため非採用 |

## 4. 実装方針

- geohashへの変換はサーバー側(action.ts / route.ts 相当の層)で行い、クライアントから送られた高精度座標をそのまま永続化・ログ出力しない
- 生の緯度経度用カラムは追加しない
- マイグレーション適用方法(`prisma db push` か `prisma migrate dev`)は既存の `deleted_at` 対応時の方針に合わせるか要確認
