# ユーザーアイコン & スコア統合コンポーネント実装計画

## 1. 目的

現在、以下2つのコンポーネントがユーザー情報とスコアをそれぞれ別々に表示している。

- `components/organisms/room/ScoreBoard.tsx` … スコア（`ScoreEntry[]`）を縦一列のランキング表示
- `components/organisms/AccessUser.tsx` … 現在アクセス中のユーザー（`PresenceUser[]`）をアイコンのみで表示（右上固定ウィジェット）

この2つを統合し、「ユーザーアイコン（タップで名前表示）＋取得ポイント」をセットにしたチップを横一列に並べ、横スクロールできるコンポーネントに一本化する。オンライン中でないユーザーは半透明表示にしてオフライン感を出す。

## 2. 現状分析

### 2.1 ScoreBoard.tsx（現状）

- Props: `scores: ScoreEntry[]`（サーバー側 `getRoomScores` で取得、`point` 降順ソート済みで渡される）
- `calculateRanks(scores)`（`lib/room.ts`）で同点順位を計算
- 縦積みリストで `順位 / ユーザー名 / ポイント` を表示
- `id="tutorial-room-score"` をチュートリアルが参照している（`hooks/tutorial/steps/room.ts:46`）ため、**このID要素は維持が必須**

### 2.2 AccessUser.tsx（現状）

- Props: `users: PresenceUser[]`（`usePresence` フックのリアルタイムプレゼンスから取得、現在接続中のユーザーのみ）
- 画面右上に `fixed` で固定表示されるアイコンリスト
- タップでアイコン⇔フルネーム表示をグローバルにトグル（`isfullName` state）
- 開閉トグル（`isOpen`）で表示/非表示を切り替え可能

### 2.3 型定義

```ts
// type/roomType.ts
export type ScoreEntry = Prisma.PointGetPayload<{ include: { user: true } }>;
// => { id, room_id, user_id, point, deleted_at, user: { id, username, icon_name, icon_color, ... } }

// hooks/usePresence.ts
export type PresenceUser = {
  user_id: string
  user_name: string
  joined_at: string
}
```

両者は `user_id` で結合可能（`ScoreEntry.user_id` === `PresenceUser.user_id`）。

### 2.4 データソースの違いに関する注意

- `scores` はサーバーから渡される props（DB由来）で、**そのルームで得点したことがある全ユーザー**を含む（オフラインでも残る）
- `users` はクライアント側のリアルタイムプレゼンスで、**現在アクセス中のユーザーのみ**を含む
- 得点があるがオフラインのユーザー → `scores` にはあるが `users` にいない → **opacity低下でオフライン表示**
- オンラインだがまだ得点していないユーザー（0点） → `users` にはあるが `scores` にいない → **0点として表示に含める**

## 3. 統合方針

### 3.1 新コンポーネント

- パス: `components/organisms/room/UserScoreBoard.tsx`（新規作成）
- 旧 `ScoreBoard.tsx` と `AccessUser.tsx` は本コンポーネントに置き換えて **削除**
- Props:

```ts
type UserScoreBoardProps = {
  scores: ScoreEntry[];
  users: PresenceUser[];
};
```

### 3.2 マージロジック（新規ヘルパー）

`lib/room.ts` に `calculateRanks` と同居する形で以下を追加する。

```ts
export type BoardEntry = {
  user_id: string;
  username: string;
  point: number;
  isOnline: boolean;
};

export function buildScoreBoardEntries(
  scores: ScoreEntry[],
  users: PresenceUser[],
): BoardEntry[] {
  const onlineIds = new Set(users.map((u) => u.user_id));

  const fromScores: BoardEntry[] = scores.map((s) => ({
    user_id: s.user_id,
    username: s.user?.username ?? '名無し',
    point: s.point,
    isOnline: onlineIds.has(s.user_id),
  }));

  const scoreIds = new Set(scores.map((s) => s.user_id));
  const fromOnlineOnly: BoardEntry[] = users
    .filter((u) => !scoreIds.has(u.user_id))
    .map((u) => ({
      user_id: u.user_id,
      username: u.user_name,
      point: 0,
      isOnline: true,
    }));

  return [...fromScores, ...fromOnlineOnly].sort((a, b) => b.point - a.point);
}
```

- 既存の `calculateRanks` はそのまま `BoardEntry[]`（`point` を持つ配列）に対しても利用可能なため流用する
- ソートはコンポーネント側でなくヘルパー内で完結させ、`RoomPage` 側の既存ソート処理（サーバー側の `scores` ソート）とは独立させる

### 3.3 UI設計

- 横スクロールコンテナ: `overflow-x-auto flex gap-3` の1行レイアウト
- 各チップ（1ユーザー分）:
  - アイコン部分（円形、`icon_color`/`icon_name` があれば反映、なければイニシャル表示）
  - タップで自分のチップだけ名前ラベルを表示⇔非表示（**個別トグル**にする。旧 `AccessUser` はグローバルトグルだったが、統合後は「タッチしたら名前も表示される」という要件どおり、タップしたアイコン単体の名前を出す方式に変更）
  - アイコンの右横にポイントバッジ（例: `123点`）
  - `isOnline === false` の場合はチップ全体に `opacity-40` 相当を適用してオフライン感を出す
- 順位表示（王冠アイコンなど）は既存 `ScoreBoard` の演出を踏襲し、1位（同点含む）に `TbCrown` を表示
- アニメーションは `motion/react`（`ScoreBoard.tsx` で使用中のもの）に統一する（`AccessUser.tsx` の `framer-motion` import は廃止し、パッケージを一本化）

### 3.4 状態管理

```ts
const [openUserId, setOpenUserId] = useState<string | null>(null);
```

- アイコンタップで `openUserId` を対象ユーザーIDにセット（再タップ or 他をタップで閉じる）
- 個別トグルなので `isfullName` のようなグローバルstateは不要

### 3.5 配置

- 現状 `AccessUser` は `fixed right-2 top-17` の固定ウィジェット、`ScoreBoard` は `RoomPage` 内のページ下部にインラインで配置、という異なる配置だった
- 統合後は **1つのセクションとして`RoomPage`内に集約** し、`id="tutorial-room-score"` はこの新セクションのルート要素に付与する（チュートリアル動線を壊さないため）
- 固定表示（`fixed`）は廃止し、`AccessUser`表示位置にあった開閉ボタン（`isOpen`）も廃止してシンプルな横スクロールリストに一本化する
  - 理由: 縦積みランキング表示と、右上固定のアイコンリストという「2箇所に分散した情報」を1箇所にまとめるのが今回の目的のため
